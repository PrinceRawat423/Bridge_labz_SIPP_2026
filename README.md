# Bridge_labz_SIPP_2026

This repository contains BridgeLabz training practice programs, assignments, coding exercises, and review documents.

## Repository Structure

```text
core-java-practice/
  gcr-codebase/
    programming-elements/
    control-flow/
  leet-code-codebase/

oops-practice/
  gcr-codebase/
    inheritance/
    encapsulation/
    polymorphism/
  leet-code-codebase/

reviews/
```

## Branches

- `core-java-practice`: Core Java practice programs, GCR assignments, and LeetCode solutions.
- `oops-practice`: OOPs assignments, practice programs, and related coding challenges.
- `reviews`: Weekly reviews, self-assessments, mentor feedback, and progress documents.

## Naming Convention

Use meaningful Java file names such as:

- `EmployeeWageCalculator.java`
- `PalindromeChecker.java`
- `StudentManagementSystem.java`
- `BankAccountDemo.java`

Avoid generic names such as `Program1.java`, `Test.java`, `Demo.java`, or `NewFile.java`.

## Commit Message Format

Use clear commit messages:

```text
[Name] Add: Added Control Flow assignments
[Name] Refactor: Improved Student Management System
[Name] Fix: Corrected Palindrome Checker logic
[Name] Update: Updated weekly review document
```
